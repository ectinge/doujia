# 豆荚 · 静态小组

直接用浏览器打开 `index.html`。无需安装依赖、账号或后端，所有图片与脚本均在本文件夹内。可独立移动整个 `doujia/` 文件夹。

## 显示宽度

统一使用手机布局，最大宽度为 430px。窄屏按屏幕宽度自适应；电脑上居中显示同样的手机页面，不放大字号、间距或缩略图。底部操作栏、图片弹窗和通知也限制在手机宽度内。修改上限只需调整 `style.css` 的 `--app-width`。

## 手机访问

在电脑终端进入本文件夹，运行 `python3 -m http.server 8080 --bind 0.0.0.0`，然后在同一 Wi-Fi 下用手机访问 `http://电脑的局域网IP:8080`。电脑需保持运行，并允许局域网连接。静态托管时上传整个文件夹即可，页面使用 hash 路由，无需服务器重写。

## 内容维护

| 文件 | 用途 |
| --- | --- |
| `content/group.js` | 小组名称、人数、简介、组规、头像 |
| `content/users.js` | 用户 ID、显示名、头像、IP 属地；`me` 为浏览者。同 ID 优先于用户库 |
| `content/user-pool.js` | 历史项目合并用户库（special 剧情人物 8／general 路人 82；带 `tags: ["暂不使用"]` 的先别引用）。帖子可直接引用库中 ID，如 `db_moon`、`wb_shanliang`；`user-pool.json` 为同内容 JSON |
| `assets/avatars/users/` | 用户库头像（256×256），`pool_*` 为未使用的备用头像 |
| `content/posts.js` | 首页帖子顺序、可读状态、正文、投票、评论 |
| `assets/avatars/` | 用户与小组头像占位 SVG，可替换为 JPG/PNG/WebP |
| `assets/images/` | 版头背景、正文与评论占位图片 |
| `templates/写作模板.md` | 先写内容的结构模板与字段说明 |
| `templates/帖子数据模板.js` | 可复制到帖子数组中的对象模板 |
| `style.css` | 蓝色主题、首页、响应式布局与交互样式 |
| `post-base.css` | 从原 douban demo 复制的帖子视觉基础 |

所有素材路径相对 `index.html`，不是相对 `content/`。更换版头背景请替换 `assets/images/cover.svg`，或修改 `style.css` 的 `.hero` 背景路径。更改主题搜索 `#397abe` 与 `--brand`。

## 阅读与交互

- 首页固定热门，最新／精华不可切换；无分类滑动栏、无悬浮发帖按钮。
- 数组顺序即首页顺序，不按点赞数自动排序。`deleted: true` 点击通知“该帖子已删除”，不生成详情；正常帖子需完整 content 与 comments。
- 下滑后版头收起为吸顶栏；组内搜索按标题或作者筛选。
- 详情支持图片放大、长图折叠、引用回复、热门回复、单／多选投票、点赞、收藏、关注、加入、发布及引用回复。
- 点赞、收藏、投票、关注、加入和新增回复保存在浏览器 localStorage，仅当前浏览器有效，不会改写 JS 文件，不同步其他设备。浏览器限制存储时仅本次有效。
- 首页回复数可以是虚构总数，不要求与展示评论数量相同。新增本地回复会加到显示总数。热门回复是从全部回复中挑选（`hot: true`）、按赞数排序后在上方再展示一次；全部回复区仍按原位置保留同一条回复，两处共用点赞状态。
- 分享复制当前页面地址；本地文件地址不能供其他设备访问，手机或跨设备分享请使用可访问的 HTTP 地址。浏览器禁止剪贴板时按通知复制地址栏。
- 链接卡片未填写 `url` 时提示失效；填写时仅允许 `http://` 或 `https://`。图片查看以手机页面宽度显示原图，其余区域纯黑；长图可滚动，点击任意位置或按 Esc 退出。
- 浏览者（`me`）新回复的时间：日期取帖子的 `updated`（最新回复日期），时间取当前时分；若早于楼内最后一条回复，则顺延到其后 1 分钟。
- 浏览者（`me`）自己发布的回复带「删除」按钮：点一次变为「确认删除」，3 秒内再点即删除，仅影响本机记录。
- 没有登录、真实发布、云数据库或平台请求。文本按纯文本转义，不支持直接注入 HTML。

清空体验记录：浏览器控制台执行 `localStorage.removeItem('doujia-v2'); location.reload()`。替换故事时建议清空旧记录，或为新帖子使用新的稳定 ID。评论 ID 在同一帖子内不可重复；投票结果按正文块索引存储，调整正文顺序后建议清空记录。

## 检查

编辑后刷新页面，依次检查：首页列表 → 可读帖子 → 返回 → 已删除帖子 → 图片放大 → 投票 → 回复 → 刷新保留状态。手机和桌面都应无横向溢出。

长帖阅读时底栏显示回复、赞、转发、收藏及数量；主楼末尾进入底栏上方后，以滑动淡入动效切换为写回复与三个操作图标。短帖直接显示写回复底栏。回复区末尾显示“没有更多回复了”。仅保留楼主身份，不展示普通成员徽章。

## 回复抽屉与返回手势

- 点击“写回复”或评论下的“回复”，回复框从底部上滑为覆盖层，帖子保持原位不滚动；点击遮罩、“取消”或按 Esc 收起，未发布的文字在同一回复对象下保留。
- 输入法：Android 通过 viewport 的 `interactive-widget=resizes-content` 让页面让出键盘高度；iOS 通过 `visualViewport` 计算键盘高度，抽屉贴在键盘上方。
- 帖子内向右划动（从屏幕任意位置）可返回首页：页面跟手移动、底下露出首页；划过约 1/3 宽度或快速轻划即返回，否则回弹。iOS Safari 自带的左边缘返回手势同样可用，此时跳过站内动画，避免重复。
